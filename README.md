# #AndrievskayaTeam — сайт

Одностраничный сайт без сборки и зависимостей: открывается с любого статического хостинга.

## Что где лежит

| Файл | Зачем |
| --- | --- |
| `index.html` | Разметка страницы и тексты разделов |
| `assets/style.css`, `assets/app.js` | Оформление и интерактив |
| `data/content.js` | **Весь редактируемый контент**: сезон, кейсы, команда, отзывы, контакты |
| `data/media.js` | Какие фото из постов Telegram-канала стоят на сайте (файлы — в `assets/media/`) |
| `assets/media/` | Фото проектов и портреты команды |
| `assets/fonts.css`, `assets/fonts/` | Шрифты (SIL Open Font License, тексты лицензий рядом) |
| `tools/photos.mjs` | Обновляет ссылки на фото или сохраняет фото в проект |
| `.github/workflows/photos.yml` | Задание «Фото в проект»: запускает `tools/photos.mjs --download` на серверах GitHub |

## Как добавить событие

Одна строка в `data/content.js`, раздел `season`:

```js
{ start: '2026-12-20', when: '20.12', title: 'Название', place: 'Где', scale: 'Масштаб', role: 'Наша роль', tags: ['ceremony'] },
```

Метки «дальше» и «сейчас» ставятся от даты `start` (и `end`, если событие идёт несколько дней): когда дата проходит, метка снимается сама.

## Фото

Все фото лежат в проекте (`assets/media/`), сайт не зависит от серверов Telegram и Tilda. Если в `tools/photos.mjs` поменяли список кадров или в `data/content.js` поставили новый портрет со старого сайта, фото нужно скачать заново. Telegram открывается не отовсюду, поэтому проще сделать это на серверах GitHub:

```bash
gh workflow run photos.yml
```

Задание скачает фото, проверит, что на месте все кадры и портреты, и закоммитит их в `main`. Если Telegram с вашей машины открывается, можно и локально: `node tools/photos.mjs --download` (Node.js 18+).

## Публикация

Сайт выложен на GitHub Pages из ветки `main`: https://gshtanov.github.io/andrievskaya-team/. Любой коммит в `main` обновляет сайт через минуту-две.

Пока это черновик, в `index.html` стоит `<meta name="robots" content="noindex, nofollow">` — он не пускает страницу в поиск. Перед настоящим запуском эту строку нужно убрать.

## Локальный просмотр

```bash
python -m http.server 4173
```

После этого сайт открыт на `http://localhost:4173`.

## Правила оформления

Вёрстка выверена по правилам [Impeccable](https://github.com/pbakaus/impeccable). Если будете править стили, держитесь их:

- цвета, скругления и шрифты берутся из переменных в начале `assets/style.css`;
- моноширинный шрифт — только для тайм-кода, часов и дат;
- над заголовками нет «надзаголовков», у списков нет декоративной нумерации;
- текст не мельче 12 px, контраст не ниже 4,5:1 (для крупных заголовков — 3:1);
- движение на странице одно: переключение камер в первом экране и стопка кейсов.
